观象 0.1.9（Android · Windows · Linux）。

官网：https://guanx.huxulm.dev

## 更新

- **Linux 版**：新增 `.deb` 安装包，适用于 Ubuntu 22.04 及以上、Debian 12 等 x64 系统。
  - 安装：`sudo apt install ./guanxiang-0.1.9-linux-amd64.deb`，之后在应用列表里打开“观象”，或在终端运行 `guanxiang`。
  - 卸载：`sudo apt remove guanxiang`。
  - 功能与 Windows 版相同：地图用 OpenStreetMap，后台任务需要保持应用打开；GPS 定位需要系统提供 GeoClue。
- 发布流程改由 GitHub Actions 完成：Linux 包在 Ubuntu 22.04 上构建，并在 22.04 和 24.04 上做安装、启动、卸载测试；所有安装包同步到 Cloudflare R2 后才更新官网。

## 已知限制

- Linux 版只在 CI 的 Ubuntu 22.04/24.04（Xvfb）上做过安装和启动测试，尚未在真实桌面环境中试用。
- 点击通知只会打开应用，不会直接跳到对应任务的报告。Windows、Linux 上的通知未实际验证。
- 新界面和主题尚未在手机真机上检查；“近期天象”会列出半影月食（肉眼几乎看不出）。
- 卫星预报尚未与 transit-finder 对比，也未经实际观测核对。
