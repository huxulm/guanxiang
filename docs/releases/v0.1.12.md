## 更新

- **分享图**：日月食详情页右上角新增分享按钮，生成适合发朋友圈的图片：月食画出食甚时的血月，日食画出你所在地看到的太阳面和一张全宽的全球食带地图，附全食时长、食分等关键数字、沙罗序列和官网二维码。观测地默认不上图，可以在预览页打开，打开后只显示取整到 1° 的经纬度。Android、Windows 可直接调起系统分享，Windows、Linux 可以保存为 PNG。
- **详情页**：日月食页上的原始参数（UTC 时刻、γ、全球食分等）收进“全部参数”按钮，点开从底部拉出，可复制；页面上只留更好读的卡片。合、冲、掩星等事件的参数表不变。
- **构建**：三个平台的安装包都改由 GitHub Actions 构建；Android 签名证书不变，可以直接覆盖升级。

## 已知限制

- “今晚”和所有时间都按手机所在的时区显示；观测地设在别的时区时看到的是手机时区的时间。高纬度地区 10 分钟内先升后落的出没会漏掉。
- 红光模式的地图滤镜只作用于 OpenStreetMap，不作用于高德地图。
- Linux 版只在 CI 的 Ubuntu 22.04/24.04（Xvfb）上做过安装和启动测试，尚未在真实桌面环境中试用。
- 点击通知只会打开应用，不会直接跳到对应任务的报告。Windows、Linux 上的通知未实际验证。
- 日月食的全球地图按 2° 网格计算，月食可见区域没有计入大气折射和视差，边界附近可能差 1° 左右。
- Linux 上分享图只能保存为文件，不能直接调起系统分享。
- 新界面和系统分享尚未在手机真机上检查；卫星预报尚未与 transit-finder 对比，也未经实际观测核对。

**观测太阳必须使用合格的太阳滤光膜（ISO 12312-2），切勿直视太阳。**
