观象隐私政策

更新日期：2026 年 11 月 6 日　适用于观象 Android、Windows 应用

观象是一个天文事件搜索工具。我们没有账号系统，不投放广告，也不使用任何统计或分析服务。天文计算全部在你的设备上完成。

1. 我们处理的信息

  • 观测位置。你在“设置”里选择“GPS 自动”时，应用会在你搜索本地可见事件、卫星凌日凌月或点“立即定位”时读取设备位置；选择“手动”时使用你输入的经纬度。位置只保存在本机（应用数据目录下的 settings.json），不会上传到我们或任何第三方，除非你使用了下面第 2 节所述的高德地图。
  • 卫星根数缓存、地图缓存。只保存在本机。卸载应用时可以一并删除。

2. 第三方服务与 SDK

以下服务只在需要时联网访问。访问时，对方服务器会看到你的 IP 地址和本应用的 User-Agent（guanxiang/版本号），这是网络请求本身决定的。

3. 权限说明（Android）

  • 位置（可只给大致位置）：仅在“GPS 自动”模式下用于确定观测地点。
  • 网络：下载卫星根数、显示地图。
  • 后台任务、开机启动、唤醒：由系统的 WorkManager 每 6 小时在联网时刷新一次卫星根数缓存。

4. 你的选择

  • 随时可以在“设置”里改用手动位置，或关闭高德地图。
  • 可以在系统设置里撤回位置权限。
  • 卸载应用会删除程序；Windows 安装版卸载时会询问是否同时删除设置和缓存。

5. 变更

本政策如有变化，会更新本页面并修改上面的更新日期。

Privacy policy (English)

Guanxiang is an astronomical event search tool. There are no accounts, no ads and no analytics; all astronomical computation happens on your device.

Location. In GPS mode the app reads your location only when you search for locally visible events or satellite transits, or tap “Locate now”. In manual mode it uses the coordinates you enter. The location is stored only on your device and is never uploaded, except as described for AMap below. Satellite element and map caches are also kept only on the device.

Third-party services. When a network request is made, the server sees your IP address and the app’s User-Agent.

  • AMap (Gaode) map SDK, AutoNavi Software Co., Ltd. — Android only, and only after you agree in the app. Used to show the satellite transit map. According to AMap, the SDK collects device information (such as model, OS version and device identifiers), network information (such as IP address and network type) and location-related information such as the displayed map area. If you decline, OpenStreetMap is used and the AMap SDK is not initialised. AMap privacy policy.
  • OpenStreetMap tiles — base map when AMap is not used. OSMF privacy policy.
  • CelesTrak — satellite orbital elements.
  • Cloudflare — hosts this website and the downloads. Cloudflare privacy policy.

Android permissions. Location (approximate is enough) for GPS mode; network for satellite elements and maps; background work, boot and wake lock so WorkManager can refresh the satellite cache every 6 hours when online.

You can switch to a manual location or turn AMap off in Settings at any time, and revoke the location permission in system settings.
